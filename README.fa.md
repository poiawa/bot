# VPN اشتراک فروشی -.bot

## توضیحات پروژه

یک پلتفرم حرفه‌ای، امن و مقیاس‌پذیر برای فروش و مدیریت اشتراک VPN/پروکسی با پشتیبانی از چند پنل، فروشندگان، رابط فارسی RTL و درگاه‌های پرداخت ایرانی.

### بازار هدف
- **اصلی**: ایران (قیمت‌گذاری تومانی، رابط RTL فارسی)
- **ثانویه**: آماده گسترش بین‌المللی

### قابلیت‌های اصلی
- ربات تلگرام مشتری
- مینی اپ تلگرام
- داشبورد مدیریت وب
- پرتال مشتریان
- ادغام چند پنل (Marzban، Marzneshin و...)
- سیستم فروشنده و برچسب سفید
- پردازش پرداخت (زرین‌پال، کارت به کارت و...)
- کیف پول و دفتر مالی
- انباره تنظیمات
- تیکت پشتیبانی
- تحلیل و گزارش‌گیری

### تکنولوژی‌ها
- **بک‌اند**: Node.js با Fastify
- **دیتابیس**: PostgreSQL با Drizzle ORM
- **کش/صف**: Redis
- **ربات**: Telegram Bot API (telegraf)
- **فرانت‌اند**: TypeScript + React + Vite
- **دیپلوی**: Docker Compose
